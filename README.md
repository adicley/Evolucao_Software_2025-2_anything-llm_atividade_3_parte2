# Atividade 3 (Parte 2) - Otimizando a Esteira de Automação
## Objetivo
A atividade consiste na implementação de duas (2) melhorias técnicas para as configurações de automação do workflow do projeto [Anything-llm](https://github.com/Mintplex-Labs/anything-llm).Nesse sentido, ao analisar os workflows nas aba Actions, foram notados a ausência de um arquivo de configuração linter atualizado para identificar eventuais problemas de formatação nos arquivos do projeto. Com isso, a equipe implementou inseriu a config de [super-linter.yaml]([https://github.com/Mintplex-Labs/anything-llm](https://github.com/adicley/anything-llm/blob/master/.github/workflows/super-linter.yaml)), utlizando o super linter do github actions, no fork do projeto o bem como criação da documentação CI (presente no documento do repositório) para rodar os workflows localmente devido ao gargalo de tempo para execuções remotas dos workflows do projeto.
